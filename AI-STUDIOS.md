# AI Studios

These 25 projects turn a review decision into a file someone can use. An editor can take an approved cut list into the edit bay, a developer can run a test-worker manifest, and a field researcher can open survey sites on a map.

Each project includes sample data, an interactive review screen and a command-line interface. You can inspect the evidence and export your choices locally. For a second opinion on the evidence, connect a local chat model, Azure OpenAI, Amazon Bedrock or a compatible API.
